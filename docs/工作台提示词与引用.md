# 工作台提示词与素材引用

每组的提示词、男主/聆听者绑定、音色和生成结果共同保存在本地项目。聊天执行时也必须读取这里的配置，并把任务写回这里，不再另外生成一套独立任务。

1. 选择图片组，在右侧“本组素材绑定”指定男主是 A 还是 B。另一张自动作为聆听者；生成优先使用修复图。
2. 点击“导入 / 更换本组参考音色”。音频复制到项目内，原文件移动后不影响已保存配置。每组独立保存音色。
3. 可直接编辑本组提示词，点击 `@男主`、`@聆听者`、`@音色` 在光标处插入引用。也可点击“按台词生成提示词”，输入台词和情绪，通过本地模板输出可编辑提示词。这一步不调用 AI 或即梦。旧版的“男主@”“音色参考@”可用“整理原有 @ 引用”升级。
4. 点击“预览提示词 / 复制执行单”，核对实际图片路径、音色和参数。准备草稿时，程序把这些具名引用转换成即梦 CLI 的实际资源引用，并上传对应图片和音频。没有绑定的音色或不认识的 `@` 会阻止草稿准备。
5. 在“即梦视频生成”设置模型、时长、画幅和分辨率。默认 Seedance 2.0 Fast、全能参考、15 秒、4:3、720P。依次准备当前组草稿、查询积分、确认提交、更新状态、下载。导出图片的复选框不控制这个“当前组”按钮。
6. 成片出现在本组“本组生成结果”，点击即可在工作台内播放。新一轮生成先点击“新建生成轮次”，旧任务与成片保留为历史。状态不确定或生成中的任务不能归档重提。

## 如何把需求准确交给聊天中的助手

当前没有内嵌聊天窗口，也不会把工作台输入自动发送给助手。点击“复制执行单给助手”，粘贴到聊天，再说明具体动作，例如“读取组 02，帮我调整情绪，先不生成”。执行单包含项目 ID、图片组 ID、提示词、图片及音色绑定、模型参数和原任务身份。

同一台电脑、同一工作目录中，也可以直接说明“读取工作台当前项目的图片组 02，以已保存配置为准”。助手必须先读项目记录，不能只依据此前聊天中的旧提示词。若组号发生重排，以执行单中的图片组 ID 为准。
